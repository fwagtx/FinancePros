# Research brief: How probate and estate lawyers get paid (2026-10-11-business)

Show: How They Make Money. No public-company 10-K applies (probate law firms are private); the "official filing" here is the statute itself, California Probate Code sections 10800 and 10810.

## Key facts (with dates)
1. Most states: probate attorney fees must be "reasonable" (often hourly or a negotiated flat/percentage fee, subject to court review). A handful of states set fees by statutory schedule; California is the best-known example. (Elayne, Jul 2026; LegalMatch state comparison.) Exact count of "statutory" states varies by source (7-8), so the script does not give a number.
2. California Probate Code 10810 (attorney for the personal representative), "ordinary" compensation, current as of Sept 2026:
   - 4% of the first $100,000
   - 3% of the next $100,000
   - 2% of the next $800,000
   - 1% of the next $9,000,000
   - 0.5% of the next $15,000,000
   - Above $25,000,000: a reasonable amount set by the court.
   (Confirmed by multiple sources quoting the statute: FindLaw/Justia/Onecle text in search snippets, settledestate.com, catalinastructuredfunding.com. Official leginfo.legislature.ca.gov page blocked for direct fetch.)
3. Estate value for the fee = inventory appraisal + gains on sales + receipts - losses on sales, "without reference to encumbrances or other obligations on estate property" (Prob. Code 10810(b)). So a mortgage does NOT reduce the fee base. (Statute text quoted in search result; sandiegoestateplanninglawyerblog; absolutetrustcounsel.)
4. California Probate Code 10800: the executor/personal representative gets the SAME schedule, separately. (Justia 10800 snippet; wealthcarelawyer.com.) Executors may waive their fee (common when the executor is also an heir) - so the script says "can claim."
5. Probate Code 10811: extra compensation for "extraordinary services" (e.g., selling real property, litigation, tax matters) as the court determines "just and reasonable" - requires a petition and court approval. (Search snippet of 10811; calattorneysfees.com.)
6. Property held in a living trust does not go through probate (California courts self-help, Santa Clara Superior Court "Living Trusts" page; OC courts).
7. California small-estate affidavit limit: $208,850 for deaths on or after April 1, 2025 (was $184,500); next adjustment April 1, 2028 (Prob. Code 13100, 890). (orangecountyestateplanningfirm.com; ttfhlaw.com.) Not used in the script.
8. Timely context: C.A.R. statewide median price of existing single-family homes, August 2026: $901,420 (July 2026: $887,210; August 2025: $900,620). (C.A.R. Aug 2026 release, via search result; edhat.) The script uses a rounded $900,000 house as a labeled example.

## Worked example (exact math) - labeled example: $900,000 gross estate (one California house)
Attorney fee (10810):
- 4% x $100,000 = $4,000
- 3% x $100,000 = $3,000
- 2% x $700,000 = $14,000  (remaining $900,000 - $200,000 = $700,000, within the $800,000 tier)
- Total = $21,000
Executor fee (10800): same = $21,000. Combined up to $42,000.
Mortgage twist (example assumption: $500,000 still owed): heirs' equity = $400,000, but the fee base stays $900,000, so the attorney fee is still $21,000 (5.25% of the $400,000 equity; 2.33% of gross).

## Chartable series: California statutory attorney fee by gross estate size (computed from Prob. Code 10810)

Effective rate falls: 4% at $100K, 2.33% at $900K, 2.3% at $1M, 1.65% at $2M.

## The surprising fact
The fee is based on the estate's GROSS value; debts like a mortgage are ignored. A mostly-mortgaged house pays the same probate fee as a paid-off one.
