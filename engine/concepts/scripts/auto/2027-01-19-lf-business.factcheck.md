## Our math (recomputed)
- Per member: $19,817M / 1.3B = $15.24, so "about $15" is right (and at most $15.24, since membership is over 1.3B).
- Per day: $19,817M / 365 = $54.29M, so $54.3M is right.
- Sum FY2017–FY2026 using the latest restated values (2,271 + 5,259 + 6,754 + 8,077 + 10,289 + 13,631 + 14,989 + 16,372 + 17,812 + 19,817) = $115,271M, so $115.3B is right. $115.271B / $26.2B = 4.40x. This is revenue, not profit, and the script says so on line 61.
- FY2018 to FY2026: 19,817 / 5,259 = 3.77x, so 3.8x is right. The rounded $19.8B / $5.3B gives 3.74x, but the exact 10-K figures support 3.8x.
